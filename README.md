# Daily Expense Tracker & Spending Analysis

## 📌 Project Overview

The Daily Expense Tracker is a Python-based data analysis project that helps track, analyze, and understand daily spending patterns. The project uses Pandas, NumPy, and Matplotlib to clean expense data, calculate key spending metrics, analyze categories, and generate useful visual insights.

## 🎯 Objectives

* Track daily expenses and spending patterns
* Analyze category-wise spending
* Compare weekday and weekend expenses
* Identify the highest-spending days and categories
* Compare actual spending with a monthly budget
* Generate meaningful insights from expense data

## ✨ Features

* Data loading and preprocessing
* Expense validation and cleaning
* Key expense KPI calculation
* Category-wise spending analysis
* Daily spending trend analysis
* Weekday vs Weekend comparison
* Top 5 highest-spending days
* Monthly budget analysis
* Budget utilization calculation
* Data visualization
* Automated spending insights

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## 📊 Analysis Performed

The project analyzes:

* Total expense
* Average expense
* Highest and lowest expenses
* Category-wise spending
* Percentage contribution of each category
* Daily spending trends
* Weekday and weekend spending
* Monthly budget usage
* Remaining budget

## 📈 Visualizations

The project includes visualizations for:

* Daily Expense Trend
* Total Spending by Category
* Weekday vs Weekend Spending
* Budget vs Actual Spending
